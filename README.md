# Nestify

## Overview
Nestify is a comprehensive PHP-based application designed to facilitate the management of house rentals. This project includes features for property listings, tenant management, rental agreements, payment tracking, and more. It aims to provide a user-friendly interface for landlords and property managers to efficiently manage their rental properties.

## Features
- **Property Listings:** Easily add, edit, and manage property listings.
- **Tenant Management:** Keep track of tenant information and rental agreements.
- **Rental Agreements:** Generate and manage rental agreements.
- **Payment Tracking:** Record and track rental payments.
- **User Authentication:** Secure login and registration for users.
- **Responsive Design:** Accessible on both desktop and mobile devices.

## Technologies Used
- **PHP:** Backend logic.
- **CSS:** Styling and layout.
- **HTML:** Structure of web pages.
- **JavaScript:** Frontend interactivity.
- **MySQL:** Database management.
- **PHPMailer:** Email handling for notifications.
